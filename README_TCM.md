# 中华医典 - 中医古籍数字平台

## 🏛️ 项目简介

中华医典是一个现代化的中医古籍数字平台，致力于传承和弘扬中华医学文化。平台收录了中国历代医学古籍1000部，卷帙上万，总字数达4亿字，汇集了新中国成立前的历代主要中医著作。

## ✨ 核心功能

### 📚 古籍库
- **1000+部古籍**: 涵盖医经、本草、方书、针灸等12个分类
- **历代医学**: 从先秦到明清，跨越两千年的医学传承
- **权威收录**: 由中医专家团队精心整理和校对
- **分类浏览**: 系统化的医学分类体系

### 🔍 智能检索
- **AI驱动**: 基于大语言模型的语义搜索
- **多维查询**: 支持古籍、方剂、症状、药材等维度搜索
- **高级筛选**: 朝代、分类、搜索范围等精准筛选
- **智能推荐**: 基于搜索结果的AI推荐系统

### 🎓 学术研究
- **论文平台**: 83篇基于古籍的学术研究论文
- **引用分析**: 完整的引用统计和分析
- **机构排行**: 研究机构和研究人员的学术影响力
- **研究趋势**: 展示中医研究的最新发展方向

## 🎯 核心页面

### 首页 (/)
- **Hero区域**: 展示平台核心价值和数据统计
- **功能导航**: 古籍库、智能检索、学术研究等入口
- **历代医学**: 按朝代展示古籍分布
- **核心特色**: 权威收录、专业整理、智能检索、学术支持

### 古籍库 (/library)
- **分类浏览**: 12个医学分类的详细展示
- **搜索筛选**: 按朝代、分类、关键词筛选
- **古籍卡片**: 展示古籍信息、作者、朝代、标签
- **统计信息**: 古籍总数、分类数量、总字数等

### 智能检索 (/search)
- **搜索类型**: 综合搜索、古籍检索、症状查询、方剂配伍
- **高级搜索**: 朝代范围、医学分类、搜索范围
- **搜索结果**: 相关度排序、时间排序、智能推荐
- **AI推荐**: 基于搜索结果的智能推荐

### 学术研究 (/research)
- **论文列表**: 最新研究论文的展示
- **统计信息**: 论文总数、被引次数、研究机构
- **机构排行**: 研究机构的学术影响力排名
- **研究趋势**: 中医研究的最新发展方向

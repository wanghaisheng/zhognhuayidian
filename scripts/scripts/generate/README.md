# 生成脚本

用于生成项目数据、路由、快照等的脚本集合

## 🚀 使用方法

```bash
node scripts/generate/[script-name]
```

## 📋 脚本列表

- `node scripts/generate/generate-routes.ts`
- `node scripts/generate/generate-snapshots.mjs`

## ⚠️ 注意事项

- 运行前请确保 Node.js 版本 >= 16
- 部分脚本可能需要特定的依赖
- 请在项目根目录下运行脚本

## 🐛 故障排除

如果遇到问题，请检查：
1. Node.js 版本是否符合要求
2. 是否在正确的目录下运行
3. 是否有必要的权限

# 概要
- 过去 3 个月，网站累计点击约 31 次，展示量显著高于 7 天窗口但 CTR 整体偏低。
- 流量集中在“历史/时间线”与首页等入口页；目录页与设备/对比页的曝光与点击均弱。
- 移动端在此周期有点击（9 次），但设备页与对比页在移动端仍无转化。

# 核心指标
- 点击：31（设备.csv 合计）
  - 桌面：22 次；移动：9 次；平板：0 次
- 展示：约 10,710（桌面 8,705 + 移动 1,937 + 平板 68）
- CTR：桌面 0.25%；移动 0.46%；平板 0%
- 平均排名：桌面 24.51；移动 7.52；平板 7.06（移动排名较好但无设备页/对比页转化）

# 国家/地区表现（国家_地区.csv）

- 英国/印度：点击各 2，展示 1,558/301，CTR 0.13%/0.66%，排名 22.54/25.96
- 中国：点击 1，展示 156，CTR 0.64%，排名 5.96（排名较好但量小）
- 长尾市场（希腊/伊朗/肯尼亚等）CTR 较高但样本量小，不作为主拓展面向。

# 页面表现（网页.csv）
- First CT Scanner（/blog/first-ct-scanner）：点击 13，展示 5,421，CTR 0.24%，排名 19.6（高曝光，低 CTR）
- 首页（/）：点击 8，展示 1,798，CTR 0.44%，排名 23.8（入口页贡献稳定）
- CT/MRI 时间线博文：各 3 次点击，CTR 0.4%–1.91%，排名 8.99–17.52（高质小流量）
- CT Scanner（/ct-scanner）：点击 1，展示 1,215，CTR 0.08%，排名 38.42（设备入口页表现弱）
- 目录与品牌页：曝光 10–35 量级，CTR 0%，排名 15–31 区间（需要结构化与聚合升级）

# 查询词洞察（查询数.csv）
- 查询集中在“历史/发明者/时间线”主题，商业意图弱、转化路径短。
- 与“制造商/设备/规格/价格”相关关键词多在 30–90 名之后，几乎无点击：
  - chinese ct scanner manufacturers：排名 14.75，点击 0
  - china 3t mri machine：排名 12.73，点击 0
  - china closed/wide mri machine：排名 7–10，点击 0
  - top ct scan manufacturers / ct scanner companies：排名 30–70+，点击 0
- 结论：需要通过“设备页/对比页/价格页”覆盖与提升这些商业意图关键词的相关性与可见性。

# 搜索结果呈现（搜索结果呈现.csv）
- 无有效“产品摘要”数据（空表），说明本周期结构化结果展示不稳定或覆盖不足。

# 问题诊断
- 内容结构与主题权重偏向历史类，未形成“设备/品牌/规格/价格/对比”的主题集群与内链。
- 设备入口页排名靠后，可能存在内容不匹配、结构化数据缺失或 SERP 摘要质量不足。
- 对比页不可见（无数据或排名过低），与用户“对比/选择”意图脱节。

# 优化建议（与 rawdata 规格联动）
- 构建“设备/规格/对比”主题集群
  - 品牌页（Product + Manufacturer Schema）→ 型号页（Product + TechSpec）→ 对比页（Article + Product + FAQ）
  - 切片数聚合页（16/64/128/256）互链型号与对比页
- 对比页批量覆盖与结构化
  - 基于 data/rawdata/specifications/*，统一规格键名/单位/★/▲/trueValue，生成可对比的规格表
  - 对比页含概览卡与证据映射（条款→证据文件→页码/图表），提升审核与用户信任
- 价格与询价路径
  - 型号价格页（如 Philips Incisive CT 价格/规格），引导询价与表单提交
  - 价格 FAQ 与“影响价格因素”科普，提升片段摘要质量
- 移动端体验与摘要
  - 对设备与对比页实现移动端首屏摘要卡、折叠表格与 FAQ 聚合，提升 CTR
  - 针对“manufacturers/specs/price/comparison”等关键词优化 SERP 文案

# 近期优先级
- P0：完成 3–5 篇高意图对比页上线（含 Schema 与证据映射）；升级 2–3 个型号价格页
- P1：设备入口页重构与规格标准化；构建切片数聚合页与品牌页互链
- P2：移动端首屏摘要优化与 FAQ 聚合；历史类博文添加内链导流至对比/设备/价格页

# 预期目标（6–8 周）
- 设备/对比相关关键词进入 20 名以内，CTR≥2%
- 移动端点击占比≥30%，设备页 CTR≥1%
- 型号价格页形成询价路径与转化闭环，推动商业意图关键词的曝光与点击占比提升
